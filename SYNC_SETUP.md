# English C1 — синхронизация между устройствами (тестовая ветка)

## Архитектура
- GitHub Pages: код приложения и публичный словарь `cards.json`. **Без личной истории.**
- На каждом устройстве: `localStorage` с карточками, историей ответов и настройками.
- Яндекс Диск: отдельные JSON-файлы для каждого устройства в выделенной папке приложения.
- Бесплатный Cloudflare Worker: пересылает **только временные ссылки скачивания/загрузки файлов Яндекс Диска**. Он не хранит пароль и не принимает OAuth-токен Яндекса.
- При синхронизации приложение объединяет события по `eventId` и перестраивает интервалы.

## Как включить
1. **На текущем основном устройстве**: English C1 → «Настройки» → экспорт JSON. Сохрани файл отдельно, чтобы можно было восстановить прогресс.
2. Зарегистрируй бесплатный аккаунт на https://dash.cloudflare.com/ .
3. В разделе **Workers & Pages** создай Worker (например, `english-c1-yandex-bridge`). Выбери бесплатный тариф, не подключай платежи или платные компоненты.
4. В редакторе Worker замени примерный код содержимым [worker/yandex-bridge.js](worker/yandex-bridge.js), нажми Deploy.
5. Скопируй адрес вида `https://english-c1-yandex-bridge.<имя>.workers.dev/`.
6. **После проверки кода** объедини изменения этой ветки с `main` через Pull Request. Дождись обновления GitHub Pages.
7. Открой English C1 → «Настройки» → «Яндекс Диск», вставь прежний **Client ID** Яндекс OAuth и адрес Worker, нажми «Сохранить».
8. Нажми «Войти через Яндекс», затем «Синхронизировать». Убедись в сообщении «Синхронизировано».
9. На втором устройстве открой English C1, добавь тот же Client ID и адрес Worker, авторизуйся в **той же учётной записи Яндекса**, нажми «Синхронизировать». История ответов объединится.
10. Для проверки отметь одну карточку на телефоне, синхронизируй; на ПК запусти синхронизацию и проверь дату следующего повторения.

## Безопасность и ограничения
- Не пересылай OAuth-токены, Client Secret и ссылки Яндекс Диска с временным доступом.
- Worker принимает запросы только с адреса GitHub Pages и только для конкретных доменов скачивания/загрузки Яндекс Диска. **CORS/Origin не является полноценной защитой от обращения к публичному Worker извне**. Подписанные URL остаются временными токенами доступа к файлу.
- Cloudflare технически обрабатывает JSON истории повторений в момент передачи. Не используй приложение для хранения секретов.
- Пока не протестирована работа с реальными временными ссылками твоего Диска; возможны ошибки 403/502, другие домены или перенаправления. При ошибке локальные данные остаются.
- В бесплатном тарифе Cloudflare Workers на дату подготовки указано до 100 000 запросов в сутки; тарифы и квоты могут меняться.
- При нескольких одновременно работающих устройствах новые события записываются отдельно и объединяются на следующей синхронизации. Для критически важной истории это не транзакционная серверная БД.
- Токен Яндекса сохраняется лишь в памяти открытой вкладки: после закрытия или перезапуска может потребоваться повторный вход.
- До подтверждения успешной работы на обоих устройствах делай регулярный экспорт JSON.

## Как откатиться
Не объединяй тестовый PR с `main`, пока не будешь готов подключить Worker. Текущий рабочий сайт останется прежним. Уже сделанные локальные резервные копии останутся доступными.
