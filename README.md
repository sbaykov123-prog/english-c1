# English C1 — персональные карточки английского

Приложение: https://sbaykov123-prog.github.io/english-c1/

## Где хранятся данные
- Публичный репозиторий `english-c1`: код сайта и общий словарь `cards.json`.
- На каждом устройстве: собственная история повторений и расписание в `localStorage`.
- Приватный репозиторий `english-c1-progress`: объединённая резервная копия, которую можно обновлять через ChatGPT и подключённый GitHub.
- Яндекс Диск НЕ используется: авторизация, сетевая синхронизация и код Яндекса удалены.

## Как переносить прогресс между Android и компьютером
1. На каждом устройстве открой «Настройки» → «Экспорт JSON».
2. Загрузи файлы в ChatGPT и попроси объединить прогресс с сохранением истории.
3. ChatGPT сохранит объединённый JSON в приватном GitHub `english-c1-progress` и предложит файл для скачивания.
4. В English C1 на каждом устройстве выбери «Настройки» → «Объединить JSON» и укажи объединённый файл.
5. Перед объединением приложение дополнительно скачает резервную копию текущих локальных данных. История объединяется по идентичностям ответов, расписание пересчитывается.

Это **не постоянная автоматическая синхронизация**: перенос прогресса требует экспорта и импорта файлов. Не передавай пароли или токены GitHub приложению.

## Добавление новых выражений
Попроси ChatGPT подготовить карточку, затем явно подтверди добавление. Через подключённый GitHub ChatGPT обновит `cards.json`; сайт получит новое выражение после обновления каталога.

## Безопасность
- Никогда не сохраняй файлы прогресса в публичном репозитории.
- Сохраняй последние несколько резервных копий для отката после ошибки.
- Файл JSON не зашифрован, поэтому не добавляй в словарь пароли и другие секреты.
- Объединение резервных копий производится локально в браузере.
- Планировщик SM-2-подобный, не официальный FSRS.
