# English C1 — версия с Яндекс Диском (тестовая)

## Что сделано

- Сохраняется текущая PWA: 69 выражений, двусторонние карточки, импорт карточек JSON, история ответов и офлайн.
- Добавлен раздел `Настройки → Яндекс Диск · синхронизация`.
- Авторизация Yandex OAuth **Authorization Code + PKCE (S256)**; разрешение **только на папку приложения** `cloud_api:disk.app_folder`.
- `client_id` — публичный идентификатор — хранится в браузере; `client_secret` **не используется**. OAuth access token живёт лишь в оперативной памяти вкладки, **не записывается в `localStorage`/файлы/GitHub**.
- Каждое устройство сохраняет собственный файл `app:/english-c1-sync-<deviceId>.json`. При синхронизации файлы всех устройств объединяются: карточки — по нормализованному выражению, ответы — по уникальным событиям; расписание пересчитывается в порядке ответов. Это устраняет обычный конфликт перезаписи одного общего файла.
- После подключения: кнопка «Синхронизировать», автообновление примерно каждые две минуты и после локальных изменений (при открытой вкладке).
- При неудаче синхронизации локальная база не удаляется; резервное копирование JSON остаётся.

## Ограничения

**Интеграция с реальным API Яндекса не проверена.** Веб-браузер может блокировать обмен кода OAuth и/или прямые запросы к REST API из-за CORS. В этом случае приложение выводит сообщение об ошибке, а работа и резервные копии по-прежнему доступны. Для гарантированного функционирования может понадобиться доверенный сервер-посредник — он **не включён** в эту полностью статическую бесплатную версию. Никаких платных услуг автоматически не создаётся.

Полноценный FSRS не реализован. Используется существующий SM-2-подобный планировщик. Секретность выражений не предполагается: `cards.json` опубликован на GitHub Pages. Учетные записи и история ответов на сайт/в GitHub не отправляются. Вся синхронизация доступна только после личного согласия Яндекс OAuth. Новые карточки из ChatGPT по-прежнему импортируются через JSON — прямой отправки из чата нет.

## Как обновить GitHub Pages (уже опубликованное приложение)

1. **Сначала** открой текущий сайт `https://sbaykov123-prog.github.io/english-c1/` → Настройки → Экспорт JSON. Сохрани бэкап отдельно.
2. Распакуй этот архив. На GitHub `https://github.com/sbaykov123-prog/english-c1` нажми `Add file → Upload files`.
3. Загрузить **файлы из распакованной папки** в корень репозитория, включая **новый `sync.js`**, `app.js`, `sw.js`, `README.md`, и подтверждай замену существующих файлов (commit).
4. GitHub Pages автоматически опубликует обновление. После публикации обнови страницу (для старого офлайн-кэша может потребоваться повторное открытие).
5. Убедись, что старые карточки и прогресс сохранились. Новая версия использует тот же ключ `english-c1-study-v1` в `localStorage`.

## Создание OAuth-приложения Яндекса

1. Открой https://oauth.yandex.ru/client/new/ и войди в свой аккаунт.
2. Создай приложение для доступа к API. Название, например, `English C1 Personal`.
3. В доступах Яндекс Диск выбери **только** `cloud_api:disk.app_folder` («Доступ к папке приложения на Диске»); не выбирай полный доступ на чтение или запись всего Диска.
4. Укажи Redirect URI **строго**: `https://sbaykov123-prog.github.io/english-c1/` (с завершающим `/`). Для веб-платформы.
5. Сохрани приложение. Скопируй **только Client ID**. **Client Secret и токены не нужно отправлять кому-либо или помещать в GitHub**.
6. На опубликованном сайте English C1 → Настройки → вставь Client ID → «Сохранить ID» → «Войти через Яндекс». Разреши доступ к папке приложения.
7. После возвращения в приложение нажми «Синхронизировать». Посмотри отображаемый статус. **Если видишь ошибку CORS — не пытайся отключать защиту браузера**.
8. После успеха проверь второе устройство: открой тот же адрес, введи тот же Client ID, войди под **тем же Яндекс ID**, нажми «Синхронизировать». Проверь, что истории объединились.

## Безопасность

- Токен не передаётся в ChatGPT и не хранится в репозитории.
- При закрытии вкладки/перезагрузке токен нужно получить заново; это осознанный компромисс без backend.
- Не публикуй JSON-бэкапы на GitHub: репозиторий публичный.
- Разрешение OAuth можно отозвать в Яндекс ID.
- Не загружай личные или конфиденциальные документы в карточки.

## Тестирование

Локально проверены синтаксис JavaScript, обработка данных и два сценария объединения истории. Авторизация реального Яндекс ID, CORS и практическая загрузка/скачивание ещё не проверены.
