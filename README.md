# English C1 — персональные карточки

Мобильное PWA для изучения английских выражений. Не требует Yandex Cloud, сервера приложений или платной подписки.

## Что готово

- 69 подтверждённых уникальных выражений: 62 из `all-cards.md` и 7 дополнительно подтверждённых в чате.
- Два направления для каждого выражения с независимым расписанием.
- Одна карточка за раз: вспомнить, нажать «Показать ответ», затем «Снова / Трудно / Хорошо / Легко».
- При «Снова» выражение возвращается в конец текущего занятия и назначается раннее повторение.
- Колоды, поиск, добавление и редактирование карточек.
- История оценок и интервальный планировщик.
- Офлайн после первого успешного посещения сайта (Service Worker); прогресс локально в браузере.
- Экспорт и восстановление JSON для резервного копирования через Яндекс Диск.
- Импорт новых карточек из ChatGPT: файл JSON или вставка JSON-текста, включая несколько выражений сразу, без обновления сайта.
- Проверка дубликатов по нормализованной фразе; у существующих выражений история повторений не сбрасывается.

## Ограничения первой версии

- Это **не официальный алгоритм FSRS**, а консервативный интервальный планировщик на основе принципов SM-2. Полноценный FSRS с оптимизацией параметров по личной истории — дальнейшее улучшение.
- Автоматической синхронизации с Яндекс Диском пока нет. Бэкапы перемещаются вручную и **восстановление полностью заменяет локальную базу**.
- Английские определения и примеры заполнены для 69 исходных выражений. Новые выражения добавляются через импорт карточек из ChatGPT.
- Если удалить данные браузера, несохранённый на Диске прогресс будет утрачен.
- Для установки на Android нужен публично доступный **HTTPS** сайт. Яндекс Диск сам по себе не является таким хостингом.

## Как проверить на компьютере

1. Распакуй архив `english-c1-pwa.zip`.
2. Открой терминал внутри папки `english-c1-app`.
3. Выполни `python -m http.server 8000` (в Windows возможно `py -m http.server 8000`).
4. Открой в браузере `http://localhost:8000`.

Не открывай `index.html` двойным нажатием: загрузка `cards.json` требует HTTP.

## Как установить на телефон

Размести содержимое папки `english-c1-app` на любом статическом HTTPS-хостинге (например, GitHub Pages или Cloudflare Pages). Открой адрес на Android в Chrome, выбери «Установить приложение» либо «Добавить на главный экран».

На GitHub Pages обычно достаточно загрузить файлы в корень репозитория и включить публикацию в `Settings → Pages`. **Не загружай резервные копии с личной историей в публичный репозиторий**: исходные файлы сайта могут быть доступны всем.

## Резервное копирование через Яндекс Диск

1. В приложении: `Настройки → Экспорт JSON`.
2. Загрузи скачанный JSON в личную папку на Яндекс Диске.
3. На другом устройстве скачай JSON и выбери `Настройки → Восстановить JSON`.
4. Перед восстановлением всегда создай резервную копию текущего устройства: импорт **заменяет** локальные карточки и историю, а не объединяет их.

Пароль, API-ключ или OAuth-токен Яндекса для этой версии не нужны.

## Файлы

- `index.html` — вход;

## Новые карточки из ChatGPT

1. Пришли ChatGPT выражение и подтверди добавление.
2. Попроси «Подготовь JSON-файл для импорта в моё приложение English C1» (можно добавить несколько фраз сразу).
3. В приложении открой **Словарь → Импорт из ChatGPT**.
4. Выбери скачанный `.json` или вставь содержимое JSON и нажми **Добавить карточки**.
5. Новые фразы появятся в нужных колодах сразу; GitHub Pages повторно публиковать не надо.

Формат данных:

```json
{
  "cards": [
    {
      "term": "to [verb] ...",
      "ipa": "/.../",
      "definition": "To ...",
      "examples": ["An example in English."],
      "ru": "Перевод",
      "note": "Usage notes",
      "deck": "Повседневные"
    }
  ]
}
```

Обязательные поля: `term`, `ipa`, `definition`, `ru`, `examples` с минимум одним примером. `deck` и `note` необязательны. Импорт добавляет новые карточки, игнорирует уже существующие выражения и при необходимости заполняет пустые поля существующих записей; уже записанная история и интервалы не изменяются. Импорт карточек и восстановление полной резервной копии — **две разные операции**. Резервная копия заменяет данные целиком.

Полностью автоматическая передача из ChatGPT напрямую в GitHub Pages в этой версии **не реализована**; нужен один ручной шаг — выбор файла или вставка JSON. Авторизацию GitHub или Яндекса для импорта делать не нужно.
